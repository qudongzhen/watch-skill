> 状态：**已实施**（2026-11-12，`e60b100` + `284b74d` + `8775c04`）。
> 决定：① 裁切图**按需生成**，不默认铺满；② **取消正文模板**，只在开头/结尾保留结构性描述。
> 遗留一个待定项：**图片放大要"自己做"还是"用浏览器原生"**，见 §7（等你实际看效果再定）。

## 7. 待定：图片放大用什么

现状是我们自己写了个灯箱（`export.py`：点图 → 全屏覆盖层居中显示，`Esc`/点击关闭）。它在**单文件 HTML** 里是唯一可行的做法，因为图片是内联的 data URI，浏览器不允许把 `data:` 当页面打开。

浏览器原生可用的替代方案：

| 方案 | 怎么用 | 代价 |
|---|---|---|
| **`<dialog>` 原生模态** | 用浏览器内建的 `dialog.showModal()`，点击背景/Esc 关闭由浏览器实现 | 仍需一段 JS 把图塞进去；跟现在的灯箱差别不大，但少写关窗逻辑 |
| **外链原图**（推荐给 zip 版） | `<a href="assets/stills/x.png" target="_blank">` | 浏览器用自带看图器打开，可滚轮/双指缩放、可另存；**但单文件 HTML 用不了**（图是 data URI） |
| **`:target` + CSS** | 点缩略图 → `#id:target` 展开成覆盖层 | 纯 CSS 无 JS；但每张图要一个锚点，URL 会变，后退键行为怪 |
| **`<details>`** | 点开就在原位展开原图 | 无覆盖层，会撑动正文；适合"想细看但不想弹窗"的场景 |

结论建议：**zip 版走"外链原图"**（真正的浏览器原生缩放），**单文件 HTML 保留灯箱**（没有更好的选择）。等你实际点过再定。

## 2. 方案 A：裁切——按需，不铺满

### 2.1 新工具 `pipeline/crop.py`（不做自动落盘）

```
py -3.14 pipeline/crop.py BV1YV411w72F_p1_fresh --at 326            # 只给候选框（Top 3）+ 区域描述
py -3.14 pipeline/crop.py BV1YV411w72F_p1_fresh --at 326 --write    # 按 Top1 生成 *_zoom1.png
py -3.14 pipeline/crop.py BV1YV411w72F_p1_fresh --at 326 --box 1420,60,500,360 --write  # 手动框
```

- 候选框来自**投影分析**：缩到 480 宽，算行/列边缘能量 → 找连续高密度带 → 面积/长宽比过滤 → Top 3。
- 只回答"哪里字多"，**不判断这是什么**（D5 不变；这是框选，不是识别）。
- 输出带**区域描述**（顶部参数条 / 右侧属性栏 / 视口中部 / 底部字幕带），供写作者判断该不该裁。

### 2.2 谁决定裁不裁

- `run.py` **不自动生成**裁切图（按需原则）。
- BRIEF 的候选帧表里，对"关键词命中 / 冻结段"这类**参数密集**的时刻加一列 `crop?` 提示（只是提示，不产图）。
- 写作者判断"这一步读者要不要抄参数"→ 要，就 `crop.py --at --write`；不要，就不裁。

### 2.3 规则（只约束"用了就必须对"，不强制数量）

| 项 | 规则 |
|---|---|
| 成对 | 裁切图必须与它的全屏图在同一小节，先全屏后放大 |
| 图注 | 裁切图必须写"这是画面哪一块"（位置词 + 用途） |
| 数量 | **不设比例要求**（0 张也不扣分）；只有当"步骤在讲参数/代码却一张可读图都没有"时才 WARN |
| 审计 | 有 `_zoom` 图但缺对应全屏图 → WARN；`_zoom` 图无图注 → WARN |

## 3. 方案 B：取消正文模板

### 3.1 契约只保留首尾结构

```
# 标题
> 一句话结论
**来源** …　**环境** …          ← 开头三件：标题 / 结论 / 来源环境
## 你将得到 　## 前置条件          ← 可选，但目录与步骤必须有
## 步骤
### 步骤 N｜mm:ss 标题 [跳转]
（正文自由：段落、列表、表格，怎么顺手怎么来）
## 结尾                     ← 收尾结构：自检清单 / 排错 / 置信度 / 附录（附录必填）
```

**取消**：每步必须三件套、必须 ≥3 条要点、必须以"怎么做"开头、必须写"判据"字样。

**保留（都是证据链，不是模板）**：

1. 每步标题带 `mm:ss` 与跳转链接；
2. 图在步骤内，且能对到时间；
3. 结尾有「置信度与缺口」+「附录：取证说明」。

### 3.2 审计改动

| 检查 | 现在 | 改为 |
|---|---|---|
| 步骤要点 ≥3 | FAIL | **删除** |
| 每步判据 | WARN | **删除** |
| 每步 ≥2 句 | — | **删除**（正文自由，不数句子） |
| 模板腔（怎么做开头占比） | — | **删除** |
| 步骤配图 | 每步 ≥1（FAIL） | **WARN**（有图更好；空话步骤没图也能过，但会提示） |
| 步骤时间 | FAIL | 保留 FAIL（可回溯的根） |
| 开头结构 | 无 | 缺"一句话结论"或"来源"→ WARN |
| 结尾结构 | 置信度 FAIL / 附录 WARN | 保留；补一条"缺自检/排错小节 → 仅提示" |
| 可读性三项（重复句/转述词/参数集中度） | WARN | 保留（这是质量，不是模板） |

## 6. 风险与否决

| 风险 | 处理 |
|---|---|
| 按需裁切 = 写作者偷懒不裁 | "讲参数的步骤没有可读图"→ WARN；BRIEF 的 `crop?` 提示只做提醒 |
| 取消模板后结构散 | 首尾结构 + 每步时间/跳转保留；可读性三项兜底 |
| 投影框选偏 | 候选 Top3 + `--box` 手动兜底 |
| 旧笔记受影响 | 继续 `note_schema` 门控，只对新包生效 |

**明确不做**：图像语义识别、自动写正文、模仿 Word 排版。
