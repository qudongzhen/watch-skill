## 1. 先量了一遍：参考仓库的三件套，两件在我们这儿是空转的

扫了 **8 篇既有笔记 / 1764 段真实转写**（whisper `base` + `vad_filter=True`）：

| 素材 | 段数 | 标点段 | 音乐幻觉段（>8s 且 <0.8 字/秒） | 全片字/秒 |
|---|---|---|---|---|
| 中文 3 篇 + 英文 5 篇 | 1764 | **0** | **0** | zh 3.3–6.9 / en 12.1–19.0 |

- **`filterSuspectSegments` 空转**：VAD 先把非语音段筛掉了。补一个直接实验：合成 60s 纯音 / 粉噪，
  同样参数跑一遍 → **0 段**（不是低分，是根本没解码）。而且中文三篇**没有任何 >8s 的段**，
  那条阈值的半边结构性够不到。照搬 = 埋一段永不生效的代码。
- **术语表是真需求**：`寒暑`×3（Godot `setter`）、`案号`×2（`暗号`）、`二低/描编/九公格`
  各×1（`BV1uf8e6dEyA`，note.md 里本来就手工记了这批错字）。
- **"压在静音里"是噪声**：13 条命中全是真话（`Here we go` / `trim`），只是那一句音量掉到 −35dB 以下。

## 3. 最终设计

### 3.1 流水线位置

```
probe → shotlist → 图版 → ASR → 关键词打分 → pick_stills → ★后处理 → research/BRIEF/transcript
```

★ 后处理必须在选帧**之后**（M3）。它的输入是**已经繁转简**的段；它的输出只影响文本与报告，不影响选帧。

### 3.2 `pipeline/asrfix.py`（纯函数 + 离线 CLI）

| 函数 | 作用 | 关键约束 |
|---|---|---|
| `to_simplified` | 繁转简（opencc，缺了就原样返回并告警） | `run.py` 复用同一实现，**不许两边各写一份**（M1 的根因） |
| `load_terms(root, note)` | 全局 `asr-terms.json` + 每篇 `terms.json` 覆盖 | `utf-8-sig`（记事本 BOM）；坏 JSON 不抛但**要报告**；`_` 开头忽略；含换行/制表符的键值拒收 |
| `apply_terms` | 单遍替换 | 长键优先；**CJK 键原样、含字母的键加 `(?<![A-Za-z])…(?![A-Za-z])`**；键==值记 `noop`；空键不插值 |
| `silence_spans` / `coverage` | 事件流折区间、算覆盖率 | 合并重叠，覆盖率先被 clip 到 1 |
| `text_in_silence` | ≥85% 且 ≥5s 落在静音里 | 只报告，不删段；`samples` 进 research，BRIEF 只给条数 |
| `health` | 段数/字数/字每秒/最大空洞（含片头片尾）/汉字占比/告警 | **不再拿 `language` 当检测结果**（M2） |
| `suspect` | 参考实现两条判据的检出数 | 恒为 0，留着是为了换后端时能立刻看到 |

**语种判据改成"文字形态"**：要 `en` 却 100% 汉字、或要 `zh` 却 80% 拉丁字母 → 报警。
这条不依赖 `language` 字段，所以不会被"请求即检测"骗过去（M2）。

**幂等的前提写在代码里**：输入永远是 `asr.json`，不是 `transcript.md`。
若词表**自己成链**（`寒暑→酷暑` 且 `酷暑→炎夏`），单遍只保证一次稳定，二次会继续变——
`load_terms` 会报 `chained`，`transcript.fixed.md` 头部也会写出来。

### 3.3 产物

| 文件 | 内容 | 是否覆盖 |
|---|---|---|
| `evidence/transcript.md` | **未校正**的机器原文 | 从不覆盖（成品笔记称其为"原稿"）|
| `evidence/transcript.fixed.md` | 词表校正稿 + 头部摘要（命中几处、体检结论） | 每次重生成 |
| `research.json` | `asr`（校正后）+ `asr_meta`（terms / in_silence / health / suspect / t2s） | 原子替换 |
| `BRIEF.md` | 新增「转写体检」一行 + 术语校正说明 + 告警 | — |

### 3.4 CLI

| 命令 | 作用 |
|---|---|
| `pipeline/asrfix.py <id>` | 只看报告（默认不写） |
| `pipeline/asrfix.py <id> --write` | 写 `research.json` + `transcript.fixed.md` |
| `pipeline/test_asrfix.py` | 33 项断言 |

## 5. 已知边界

1. **词表成链**时二次运行会继续变（如上）；这是"用精确串替换"的固有性质，只报告不拦。
2. **`health` 抓不住 D11 的"整片乱码"**：那种形态靠的是"大空洞"（`run.py` 原本就有）和
   "文字形态对不上"。它不能凭空知道音频本来是英文——不要再用错误理由撑它。
3. **静音一致性现在几乎不报**（0.85 阈值下现有语料 0 命中）。它是守卫，不是信号。
4. **术语表会跨片污染**：`案号→暗号` 是这集的梗，放进全局表会污染任何法律素材——
   所以这类只写 `notes/<id>/terms.json`；全局表只放跨片重复的错字。
