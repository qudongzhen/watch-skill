# 实施方案：引文出处体检（无 OCR 版）

> 来源：上一轮讨论"OCR 值不值得做"的结论——OCR 唯一的真价值是**核验引文**，不是修转写。
> 状态：**已实施**（D20；不进笔记验收，按需跑 `quote_check.py`）
> 前置：D14–D19；`selfcheck` 19 项、五个 `test_*.py` 全绿
> 注（2026-11-02）：`work/tmp/verify_*.py` 已随清理删除（`docs/plan-cleanup.md`），
> 四种试法的结论留在下文，复现需按描述重写。

## 1. 先测了四种"自动核验"，全都有大量误报

在 8 篇既有笔记上逐一试过（脚本留在 `work/tmp/verify_*.py`）：

| 方案 | 测法 | 结果 | 为什么不行 |
|---|---|---|---|
| A 引文溯源 | 像口播的引文（≥8 字 + 含口语虚词）在转写里找 | 10 条里 6 条"找不到" | 找不到的多是笔记自己的措辞（"玩家该看的东西变了吗"） |
| B 章节对时 | 标题关键词 vs 该时刻 ±20s 的转写 | 59 条里 44 条"对不上" | p1–p4 是**中英对照**（中文标题、英文转写），相似度恒为 0 |
| C 图注自洽 | 文件名里的秒数 vs 正文就近时间戳 | 48 处里 42 处"对不上" | 写作者取的是**能说明这一步的那一帧**，不是小节起点，合法 |
| D 无来源引文 | 转写找不到 + 附近没有原帧 | 91 条引文里 12 条 | 同上：多半是强调用的引号 |

**结论**：笔记的写法没有给机器留下可判定的锚点——引号既用于引语也用于强调，
而"到底是不是原话"只有**看画面**才知道。所以没有 OCR，就判不了真假。

## 2. 能判定的是另一件事：**有没有出处**

把问题从"这句是真的吗"换成"这句**凭什么**"：
- 是转写里的话 → 应该能在 `research.asr` 里找到（近似即可，允许同音错字）；
- 是画面上的字（代码/菜单/硬字幕）→ 附近应该有可核的原帧（`assets/stills/`）或至少标了 `mm:ss`；
- 两样都没有 → **没出处**，要么补时间戳，要么标"读屏"，要么删。

这个判据不依赖 OCR，且**不会误杀**：它只要求作者说清来源，不判断来源真假。

## 3. 设计

### 3.1 `pipeline/quote_check.py`（纯函数）

```python
def extract(md_text) -> list[dict]     # {text, line, stamps:[秒], marker:bool}
def classify(q, segs, still_secs) -> dict   # {transcript:(ratio,秒), image:bool, verdict}
def report(note_dir) -> dict           # 汇总：总数/有出处/仅时刻/无出处
```

- 引文口径：`「」『』“”""` 成对包裹、≥6 个实义字符；**行内代码（反引号）不算引文**（那是参数）。
- `marker`：同一行或上一行出现 `原文|原话|字幕|转写|照录|读屏|画面上的字` 之一。
- `transcript`：与该笔记 `research.asr` 逐段算 LCS 覆盖率，取最高（≥0.6 视为"转写里有"）。
- `image`：附近 `±15s` 内存在 `research.stills` 的取图时刻。
- 判定：
  - `有出处`：marker 为真，或（有 stamps 且 transcript≥0.6 或 image）；
  - `仅时刻`：有 stamps，但转写与原帧都够不着 → 多半是读屏，建议补"（读屏）"；
  - `无出处`：既没 stamps 也没 marker。

### 3.2 **不进** `note_audit`（改方案）

原计划加一条 WARN。实测后改主意：8 篇存量笔记的 49 条引文里 **35 条没有出处**
（其中中文那篇 `BV1Xdnc6jEbL` 12 条里 9 条有出处，英文课的引文因中英对照天然对不上）——
这是**写法约定缺失**，不是笔记写错了。把它做成 WARN 会让 8 篇全部变黄，而 D7 明确说过
质检只查形式、且不能追溯性地把旧产物判死。

所以：**`quote_check.py` 独立、按需跑**；约定写进 `NOTE_CONTRACT` 只管**新写的**笔记。
`selfcheck` 仍然 0 FAIL / 0 WARN，不受影响。

### 3.3 `NOTE_CONTRACT` 增补一条

> 引语（转述别人的话）必须带出处：`（00:12，原话）` 或 `（读屏）`。强调不要用引号，用**加粗**。
> 机器只检查"有没有出处"，不检查真假——真假要靠人回原帧看。
> 自查：`py -3.14 pipeline/quote_check.py <id>`。

## 4. 验收

| # | 判据 | 判法 | 结果 |
|---|---|---|---|
| 1 | 引文抽取：成对引号、排除反引号代码与代码块、≥6 实义字、同一行多条 | 单测 | ✅ |
| 2 | 出处标记只认**括注**；正文里顺嘴提"转写"不算；上一行的括注不被下一行蹭走 | 单测 | ✅ |
| 3 | 分类：转写命中 / 时刻附近有原帧 / 两者皆无 | 单测 | ✅ |
| 4 | CLI `--strict` 有无出处时退出 1，都有时 0 | 单测 | ✅ |
| 5 | `selfcheck` 仍 **0 FAIL / 0 WARN**（不进 note_audit） | 实跑 | ✅ |
| 6 | 8 篇实跑：49 条引文 → **有出处 13、仅时刻 1、无出处 35** | 实跑 | ✅ |

**第 6 条怎么读**：35/49 不是笔记写错了，是**这批笔记写的时候没有出处规矩**；
其中 `BV1Xdnc6jEbL`（中文观点片）12 条里 9 条有出处，说明只要转写能覆盖，这条检查是有区分度的。
另外英语课那几篇的引文是中文转述、转写是英文，天然对不上——这类要看"有没有标时刻"。

> 判定口径经过一次修正：最初要求"必须标时刻"才算有出处，导致**转写里 1.00 命中**的引文
> 也被判"无出处"。现在改成"任一来源成立即可"（括注 / 转写命中 / 附近有原帧）。

## 5. 风险

| 风险 | 缓解 |
|---|---|
| 把"强调引号"误报成无出处 | 只报数量与前 3 条，供人看；`--strict` 默认关闭 |
| 中英对照（p1–p4）转写命中率天然低 | 这类会落到"仅时刻/无出处"，但每条都带 `mm:ss`，`--strict` 不用于外语素材 |
| 与 OCR 核验重复 | 不重复：这里判"有没有出处"，OCR 判"出处对不对"；后者是下一步 |
